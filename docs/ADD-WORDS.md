# 添加自定义词条

## 用词条工具

从开始菜单打开「寒淋输入法」→「自定义词条」。源码目录里的 `src\tools\WordManager.vbs` 也可以双击打开。窗口标题下显示当前编辑的词表路径。

添加英文词时填写标准词，例如 `ChatGPT`。编码留空会使用小写拼写，中文词需要填写编码。也可以选中词条编辑编码、调整权重或删除。修改保存后，点击「部署词条」让当前输入法载入。

相同词条和编码的旧大小写记录可在部署时合并。同一个词的不同编码仍可分别查询和编辑。部署会重新生成造句词表，并备份本次替换的文件。

## 手动编辑

`custom_phrase.txt` 每个英文词只需一行，两列之间用 Tab 分隔。

```text
ChatGPT	chatgpt
Transformer	transformer
杨寒淋	yanghanlin
```

带数字的型号可以使用已有短码。保留自定义中文短码的第三列权重。

## 输入与候选

`chatgpt`、`CHAtgpt`、`chaTGpt`、`CHatG`、`chatg`、`ChAtg` 均依次给出 `ChatGPT`、`chatgpt`、`CHATGPT`。标准词和其中一个大小写变体相同时，只显示一条相同文本。

2–4 位的英文前缀仍使用较低权重，5 位及以上的前缀优先显示英文组。单字母英文补全继续让位于拼音简拼。
